Use it today

Do these three things before you start.

Read the parent guide ->
  1. Print both page types. The student worksheet is for drawing. The support guide is for parent help.
  2. Use a pencil and eraser. No tablet, ruler, extra drawing paper, or special supply run is needed.
  3. Set a 30-minute window. Keep the goal small: try the rhythm, notice what helps, and let the student work.

During the lesson

Keep correction light and momentum high.

If your student gets stuck

Look at the matching support guide, choose one prompt or example, then return attention to the worksheet.

If the drawing feels messy

That is normal. This lesson is training pencil control and attention, not producing a perfect finished artwork.

If they finish quickly

Pick one exercise box and repeat it more slowly. Repetition is where the skill starts to show up.
